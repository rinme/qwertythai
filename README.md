# qwertythai

Simple Next.js web app that translates mistyped QWERTY keyboard text into Thai characters.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## Deploy to Vercel

This project is Vercel-ready (standard Next.js App Router setup).

1. Import this repository into Vercel.
2. Keep the default Next.js build settings.
3. Deploy.
